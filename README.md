# Minecraft Adventure Tracker v2.0

GitHub Pages 用の静的ウェブアプリです。`index.html`、`style.css`、`app.js`、`planner.js` をリポジトリのルートにアップロードしてください。

## 主な機能
- 装備19種類の進捗管理とカテゴリ別表示
- 装備別のオプションエンチャント選択（棘の鎧、火属性など）
- 金床プランナー：単一エンチャント本のレベル選択、必要冊数自動算出、合成工程・左右の配置・各工程の想定コスト
- コマンド作成、探索記録、座標換算、JSONバックアップ

## 金床プランナーの注意
新品装備と金床未使用の単一エンチャント本を前提に、統合版向けのエンチャント重み・作業ペナルティを使って探索します。計算量を抑えるため候補を絞った推奨プランです。**数学的な最安値は保証しません**。ゲーム内の実際の金床表示を優先してください。計算対象は最大10冊です。複数エンチャント付きの本、使用済み装備、特殊な互換性、バージョンによる細かな仕様差は対象外です。

## 更新
GitHub の `https://github.com/yukiapps/minecraft-adventure-tracker/upload/main` から4ファイルを同名で更新してください。公開反映後、ブラウザで再読み込みしてください。

## 保存
データはブラウザ内のlocalStorageに保存されます。設定画面からJSONを出力できます。端末間の自動同期はありません。
