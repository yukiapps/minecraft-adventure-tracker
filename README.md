# Minecraft Adventure Tracker v1.2

## 更新
- 草ブロックと記録モチーフのアイコンをサイトヘッダー、favicon、ホーム画面アイコンに設定。
- コマンド表示を一行・横スクロールにし、コピー欄とボタンを56pxに統一。
- 狭い画面でのボタン幅を調整。
- 装備・コマンド・探索記録・設定のロジックはv1.1から変更なし。

## 公開方法
ZIPを展開し、全9ファイルをGitHub Pagesのリポジトリ直下にアップロードしてください。古いファイルは上書きします。

ホーム画面に追加済みの場合、アイコンの更新にはショートカットを削除して再追加する必要があることがあります。
