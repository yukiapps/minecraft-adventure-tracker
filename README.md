# Minecraft Adventure Tracker v2.1

## 更新内容
- 槍のエンチャント表記を「ランジ」からiOS統合版の「突進」に変更。
- 「忠誠のトライデント」「激流のトライデント」を追加（装備21種類）。
- 忠誠と召雷は同じトライデントに設定可能。激流は忠誠・召雷と競合するため別装備に設定。
- 金床プランナーのトライデント用エンチャント費用と競合判定を追加。
- 既存装備のIDを維持し、保存済みの「ランジ」の進捗は「突進」に読み替え。

## 注意
金床プランナーは探索幅を絞った推定計算です。最安値の数学的保証はなく、実際の金床表示で確認してください。新品装備・金床未使用本が前提です。

## 更新方法
ZIP内の5ファイルをGitHubリポジトリのルートにアップロードしてコミットしてください。
# Minecraft Adventure Tracker v2.0

GitHub Pages 用の静的ウェブアプリです。`index.html`、`style.css`、`app.js`、`planner.js` をリポジトリのルートにアップロードしてください。

## 主な機能
- 装備19種類の進捗管理とカテゴリ別表示
- 装備別のオプションエンチャント選択（棘の鎧、火属性など）
- 金床プランナー：単一エンチャント本のレベル選択、必要冊数自動算出、合成工程・左右の配置・各工程の想定コスト
- コマンド作成、探索記録、座標換算、JSONバックアップ

## 金床プランナーの注意
新品装備と金床未使用の単一エンチャント本を前提に、統合版向けのエンチャント重み・作業ペナルティを使って探索します。計算量を抑えるため候補を絞った推奨プランです。**数学的な最安値は保証しません**。ゲーム内の実際の金床表示を優先してください。計算対象は最大10冊です。複数エンチャント付きの本、使用済み装備、特殊な互換性、バージョンによる細かな仕様差は対象外です。

## 更新
GitHub の `https://github.com/yukiapps/minecraft-adventure-tracker/upload/main` から4ファイルを同名で更新してください。公開反映後、ブラウザで再読み込みしてください。

## 保存
データはブラウザ内のlocalStorageに保存されます。設定画面からJSONを出力できます。端末間の自動同期はありません。


## v2.2 更新
- 構造物検索を25項目に拡張、地上・地下・海洋・ネザー・エンドのカテゴリを追加。
- 設定からアプリ専用Cache Storageの削除と同一スコープのService Worker解除、再読み込みに対応。ブラウザ全体のキャッシュは対象外。
- 全装備の進捗、探索記録、全登録データをそれぞれ初期化可能。
- 装備編集から個別装備の進捗だけをリセット可能。
- JSON復元時のオプションエンチャント設定の引き継ぎを修正。
- iPhoneで古い画面が出る場合は、URL末尾に `?v=22` を付けて再読み込み。
